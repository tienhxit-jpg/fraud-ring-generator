# Thông tin chạy import synthetic data lên Neo4j
# File này dùng để lưu sẵn lệnh/tham số, tránh phải gõ lại parser nhiều lần.

## 1. Thông tin kết nối Neo4j

NEO4J_URI=bolt://localhost:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=<điền_password_neo4j_của_bạn>
NEO4J_DATABASE=neo4j

## 2. Đường dẫn data synthetic v2

DATA_DIR=data/synthetic/v2
RAW_DIR=data/synthetic/v2/raw

Các file đang được importer đọc:
- data/synthetic/v2/raw/accounts.csv
- data/synthetic/v2/raw/merchants.csv
- data/synthetic/v2/raw/transactions.csv

Importer hiện KHÔNG tạo node/relationship ground-truth fraud ring:
- Không tạo (:FraudRing)
- Không tạo (:Account)-[:MEMBER_OF]->(:FraudRing)
- Không tạo (:Transaction)-[:PART_OF]->(:FraudRing)

Nhưng vẫn giữ nguyên các field đánh dấu fraud từ CSV:
- Account.fraud_ring_member
- Transaction.is_fraud
- Transaction.fraud_ring_id
- Transaction.cycle_num

## 3. Lệnh import khuyến nghị

python src/neo4jupdate/import_synthetic.py \
  --data-dir data/synthetic/v2 \
  --uri bolt://localhost:7687 \
  --user neo4j \
  --password <điền_password_neo4j_của_bạn> \
  --database neo4j \
  --batch-size 100 \
  --clear \
  --clear-batch-size 500 \
  --verify

## 4. Lệnh import nếu đã export biến môi trường

export NEO4J_URI=bolt://localhost:7687
export NEO4J_USER=neo4j
export NEO4J_PASSWORD=<điền_password_neo4j_của_bạn>
export NEO4J_DATABASE=neo4j

python src/neo4jupdate/import_synthetic.py \
  --data-dir data/synthetic/v2 \
  --batch-size 100 \
  --clear \
  --clear-batch-size 500 \
  --verify

## 5. Lệnh kiểm tra script trước khi import

python src/neo4jupdate/import_synthetic.py --help
python -m py_compile src/neo4jupdate/import_synthetic.py
python -m unittest tests.test_import_synthetic -v

## 6. Lệnh chạy cycle detection sau khi import

### Cypher fixed mode
# Với graph lớn (ví dụ 1M nodes / 2M relationships), ưu tiên --mode anchored để tránh Neo4j
# MemoryPoolOutOfMemoryError do unanchored 3/4/5-cycle expansion.
python src/cycle_detection/cypher_cycle_detection.py \
  --mode anchored \
  --limit 1000 \
  --anchor-limit 10000 \
  --require-fraud-evidence \
  --min-internal-transactions 3 \
  --min-fraud-score 0.35 \
  --jsonl-out data/cycledetection/cypher_cycle/v03.jsonl

# Chỉ dùng fixed/component unanchored khi graph nhỏ hoặc đã có filter rất mạnh.
python src/cycle_detection/cypher_cycle_detection.py \
  --mode component \
  --limit 500 \
  --require-fraud-evidence \
  --min-internal-transactions 3 \
  --min-fraud-score 0.35 \
  --jsonl-out data/cycledetection/cypher_cycle/v03_component.jsonl

### GDS mode
python src/cycle_detection/gds_cycle_detection.py \
  --limit 500 \
  --min-component-size 3 \
  --max-component-size 12 \
  --min-fraud-score 0.35 \
  --jsonl-out data/cycledetection/gds_cycle/v03.jsonl

### Hybrid NetworkX mode
python src/cycle_detection/hybrid_networkx_cycle_detection.py \
  --max-cycle-length 8 \
  --min-component-size 2 \
  --max-component-size 12 \
  --limit 1000 \
  --require-fraud-evidence \
  --min-internal-transactions 3 \
  --min-fraud-score 0.35 \
  --jsonl-out data/cycledetection/hybrid_cycle/v03.jsonl

## 7. Ghi chú quan trọng

- Dùng --clear sẽ xoá toàn bộ database Neo4j hiện tại trước khi import. Script đã xoá theo lô nhỏ bằng --clear-batch-size để tránh lỗi MemoryPoolOutOfMemoryError.
- Nếu gặp Neo.TransientError.General.MemoryPoolOutOfMemoryError, chạy lại với batch nhỏ hơn, ví dụ: --batch-size 50 --clear-batch-size 200.
- Nếu không muốn xoá DB, bỏ --clear.
- Nếu Neo4j báo lỗi authentication, kiểm tra lại NEO4J_PASSWORD hoặc tham số --password.
- Importer đang dùng schema:
  (:Customer)-[:OWNS]->(:Account)
  (:Account)-[:SENT]->(:Transaction)-[:RECEIVED_BY]->(:Account)
- Ground truth fraud ring chỉ nên dùng để đánh giá ngoài graph, không import thành node để tránh detector nhìn thấy answer-key.

## 8. Lệnh import data genCycle

Script mới cho `./data/genCycle`:

python src/neo4jupdate/import_gen_cycle.py \
  --data-dir data/genCycle \
  --uri bolt://localhost:7687 \
  --user neo4j \
  --password <điền_password_neo4j_của_bạn> \
  --database neo4j \
  --batch-size 100 \
  --clear \
  --clear-batch-size 500 \
  --verify

Nếu đã export biến môi trường:

python src/neo4jupdate/import_gen_cycle.py \
  --data-dir data/genCycle \
  --batch-size 100 \
  --clear \
  --clear-batch-size 500 \
  --verify

Ghi chú genCycle:
- Script đọc shard `accounts/accounts_*.csv`, `transactions/transactions_*.csv`, `fraud/fraud_cases.csv`, `fraud/transactions_fraud.csv`.
- Script chuẩn hoá schema giống `src/neo4jupdate/import_synthetic.py`: `(:Customer)-[:OWNS]->(:Account)` và `(:Account)-[:SENT]->(:Transaction)-[:RECEIVED_BY]->(:Account)`.
- Mặc định KHÔNG import cột `embedding` vì rất lớn; chỉ dùng `--include-embedding` nếu thật sự cần lưu vector pipe-delimited vào Neo4j.
